# AIFarm MVP 架构

## 1. 架构目标

架构将“自然语言和角色表达的不确定性”与“游戏规则和执行的确定性”隔离。运行场景固定为一名 NPC、3×3 九个地块和胡萝卜一种作物。Unity 独立拥有完整可玩逻辑；本地 FastAPI/LLM 仅是可拔除的解释与表现增强层。

## 2. 系统边界

```text
玩家文本
  → Unity 命令协调器
    → 本地目标解析器（始终可用）
    → 可选 FastAPI 网关 → LLM
  → Unity 响应校验器
  → Unity 确定性规划器
  → 动作执行器
  → 权威世界状态（农田、时间、背包、NPC）
  → 场景与 UI
```

FastAPI 不连接或修改 Unity 对象。它只接收必要的只读上下文，并返回候选高层目标、台词和表情标记。Unity 对返回值做白名单校验；失败时使用本地结果。

## 3. Unity 侧职责

| 模块 | 职责 |
| --- | --- |
| 输入与 UI | 接收文本；显示时间、背包、目标、当前动作和 NPC 表达 |
| 命令协调器 | 选择在线或离线解释路径，处理 3 秒超时和回退 |
| 本地目标解析器 | 在无服务时识别固定演示目标并提供确定性确认表达 |
| AI 网关客户端 | 向本地 FastAPI 发送文本和最小只读上下文；不承载游戏规则 |
| 响应校验器 | 只接受白名单内的高层目标、台词和表情标记 |
| 确定性规划器 | 根据目标和当前状态生成 Unity 动作；固定按地块 1–9 执行 |
| 动作执行器 | 检查前置条件，执行一个动作，并返回成功或明确失败 |
| 农田域状态 | 保存九个地块的阶段、含水、施肥、杂草和成熟状态 |
| 时间系统 | 推进加速时间并触发确定性的生长节点 |
| 背包系统 | 保存并原子更新种子、水、肥料和胡萝卜数量 |
| NPC 表现 | 移动到目标地块，播放体块化动作反馈，展示台词/表情 |

## 4. FastAPI 网关职责

本地 Python FastAPI 网关负责校验请求、调用已配置的 LLM、把结果收敛到允许的高层目标和角色表达，并返回错误或超时状态。它不得生成可直接执行的低层动作列表，不保存权威游戏状态，也不是 Unity 启动或运行的依赖。密钥仅通过本地环境变量或未跟踪配置提供。

## 5. 数据契约边界

概念契约只包含以下信息：

- **输入：** 用户原文、允许的高层目标列表、NPC 人设摘要，以及不含可变引用的只读状态摘要。
- **AI 输出：** 一个候选高层目标、NPC 台词、有限集合中的表情标记。
- **Unity 计划：** Unity 内部产生的动作类型、目标地块编号及前置条件。
- **动作结果：** 成功/失败、失败原因和已经由 Unity 提交的状态变化。

MVP 只允许一个高层目标：完成九块地的胡萝卜全周期。任何其他作物、坐标、动作类型或状态修改指令均视为无效 AI 输出并触发本地回退。

## 6. 确定性状态转换

| 事件/动作 | 前置条件 | Unity 状态变化 |
| --- | --- | --- |
| 播种 | 地块为空；种子至少 1 | 地块已播种；种子减 1 |
| 浇水 | 地块已播种；水至少 1 | 地块水分增加；水减 1 |
| 施肥 | 已浇水；肥料至少 1 | 地块已施肥；肥料减 1 |
| 时间触发杂草 | 已施肥；达到固定生长节点 | 地块进入需除草状态 |
| 除草 | 地块需要除草 | 清除杂草并继续生长 |
| 时间触发成熟 | 已除草；达到固定成熟节点 | 地块成熟 |
| 收获 | 地块成熟 | 胡萝卜加 1；地块回到空闲 |

计划分阶段处理全部九块地：播种 → 浇水 → 施肥 → 等待 → 除草 → 等待 → 收获。每个阶段内部固定按 1–9 顺序执行。

## 7. 在线、离线与故障流程

- **离线：** 本地解析器生成受支持目标和固定表达，直接进入校验与规划；所有游戏功能可用。
- **在线：** FastAPI 返回更自然的目标解释和表达；通过校验后仍进入同一个 Unity 规划器。
- **不可达/超时/无效响应：** 协调器在 3 秒内放弃 AI 结果，展示离线表达并继续执行，不回滚已完成的合法动作。

## 8. 未来目录边界

实现阶段的 Unity 代码统一置于 `My project/Assets/AIFarm/`，按 Domain、Application、Infrastructure、Presentation 和 Tests 分离。FastAPI 代码统一置于仓库根目录未来的 `Server/`。本里程碑不创建这些目录或任何代码。
