# AIFarm MVP 执行计划

## 1. 执行原则

按下列里程碑顺序推进，一次只完成一个里程碑。每个阶段必须保持 Unity 可运行、离线主路径优先、状态由 Unity 权威管理。不得因为接入 AI 而推迟确定性游戏逻辑，也不得加入 `REQUIREMENTS.md` 明确排除的内容。

## M0：文档基线（当前里程碑）

**交付物：** `REQUIREMENTS.md`、`ARCHITECTURE.md`、`ACCEPTANCE_TESTS.md`、`EXECUTION_PLAN.md`、`DEMO_SCRIPT.md`。

**完成条件：** 五份文档对 NPC、3×3 农田、胡萝卜、动作顺序、初始/最终背包、离线运行和 AI 边界的描述一致；验收项均有明确步骤和通过/失败标准。本里程碑不创建代码、场景内容或依赖。

## M1：体块化场景与可观察 UI

**范围：** 建立一名 NPC、九个编号地块和基础相机；建立文本输入、游戏时间、背包、当前目标和当前动作显示。只使用 Unity 基础体块与材质。

**验证：** 满足 AT-01 的场景数量、布局和初始 UI；Unity 无编译错误。

## M2：确定性农田域、时间与背包

**范围：** 建立九个地块的状态、胡萝卜固定生长节点、加速时间和背包原子更新；实现各状态转换的前置条件。先完成与 MonoBehaviour 解耦的域逻辑，再连接可见状态。

**验证：** Edit Mode 测试覆盖合法转换、非法转换不改状态、种子/肥料扣减和胡萝卜产出；手动验证 UI 与权威状态同步。

## M3：确定性规划与 NPC 执行

**范围：** 将唯一高层目标分解为播种、浇水、施肥、等待、除草、等待和收获；所有农田阶段按地块 1→9；NPC 仅执行 Unity 规划器给出的动作。

**验证：** 通过 AT-03 至 AT-07；完整流程在 120 秒内结束；相同输入可重复得到 0/0/9 的最终背包。

## M4：离线自然语言入口与角色表现

**范围：** 增加支持固定演示命令及等义表达的本地解析；增加确定性的确认、当前动作和完成表达。该阶段仍不依赖 Python 或网络。

**验证：** FastAPI 未运行时通过 AT-02、AT-06 和 AT-09 的核心路径；Play Mode 测试覆盖命令到完成的集成流程。

## M5：可选 FastAPI/LLM 增强

**范围：** 在根目录 `Server/` 实现本地 FastAPI 网关；定义最小请求/响应契约；Unity 增加带 3 秒上限的客户端、响应白名单校验和离线回退。LLM 只返回高层目标和角色表达。

**验证：** 在线时通过 AT-08；服务关闭、超时和无效响应时通过 AT-09；确认仓库内没有 API 密钥。此里程碑不得改变 M3 的规划或状态规则。

## M6：验收与演示固化

**范围：** 按 `ACCEPTANCE_TESTS.md` 完整执行并保存证据；按 `DEMO_SCRIPT.md` 排练离线主演示和在线可选段；只修复阻塞验收的问题。

**完成条件：** AT-01 至 AT-07、AT-09 全部通过；若宣称 AI 增强完成，则 AT-08 也通过；无编译错误或隐藏失败；文档与实际行为一致。

## 2. 依赖与停止条件

M1→M2→M3→M4 是离线核心的严格依赖链；M5 只能在离线流程通过后开始；M6 最后执行。任一里程碑出现状态不确定、离线不可用、依赖范围扩大或验收定义冲突时，停止进入下一阶段并先修正文档或当前阶段。
